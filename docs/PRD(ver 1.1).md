# 1. 서비스 개요

## 1-1. 서비스 소개

발달장애인 보호자의 일상 기록에서 AI가 개인별 돌봄 정보를 추출·축적하고, 돌봄 담당자에게 필요한 정보를 맞춤형 설명서로 전달하는 **AI 기반 돌봄 인수인계 플랫폼**

보호자의 돌봄 공백 및 소진·위기 신호를 파악하고, 용인시 공공데이터와 복지사업 정보를 활용해 관련 돌봄 자원·지원제도 안내

## 1-2. 핵심 기능

| 번호 | 핵심 기능 | 주요 내용 |
| --- | --- | --- |
| 1 | AI 기반 돌봄 기록·설명서 관리 | 음성 일기(STT), LLM 공감 한 줄, AI 돌봄 정보 추출, 보호자 승인, 설명서 자동 갱신, 주간 리포트 |
| 2 | 보호자 주도 맞춤형 돌봄 기록 공유 | 보호자가 공유할 돌봄 정보를 직접 선택·구성하여 공유 링크 발급 및 접근 권한 관리 |
| 3 | AI 기반 돌봄 공백 감지 및 공공자원 연계 | 공백 직접 입력·AI 감지, 소진·위기 신호 대응, 공공데이터 기반 돌봄기관·지원제도 안내 |

- 실제 기관 이용 가능 여부에 대한 AI의 확정적 판단 금지
- 고령 보호자를 고려한 단순한 화면 구조 및 음성 중심 입력

- 공유 시점의 내용을 고정
- 이후 설명서 변경 내용은 기존 공유본에 자동 반영하지 않음
- 최신 내용 전달 필요 시 새 공유본 생성

## 2-2. 공동 관리자 초대 흐름

**주 보호자의 일방적인 지정 요청 및 상대방 수락을 기반으로 한 권한 부여 구조**

1. 주 보호자가 마이페이지에서 공동 관리자 초대 선택
2. 상대방의 서비스 계정 ID 입력
3. 서버에서 대상 계정 존재 여부 확인
4. 주 보호자가 대상 계정 확인 후 초대 발송
5. 대상자의 계정 내 받은 초대 알림 생성
6. 대상자 로그인 후 수락 또는 거절 선택
7. 수락 시 공동 관리자 관계 생성 및 권한 활성화
8. 거절 시 초대 종료 및 권한 미부여

### 초대 상태

| 상태 | 의미 |
| --- | --- |
| PENDING | 초대 발송 완료, 수락 대기 |
| ACCEPTED | 수락 완료, 공동 관리자 권한 활성화 |
| REJECTED | 초대 거절, 권한 미부여 |
| CANCELED | 주 보호자의 대기 중 초대 취소 |
| REVOKED | 기존 공동 관리자 권한 철회 |

**권한 활성화 기준:** `ACCEPTED` 상태와 실제 유효한 관리자 권한이 모두 확인된 경우에만 접근 허용

## 2-3. 공통 레포트 공유 흐름

3. 공개 섹션·비상 연락처 포함 여부 선택(연락처 기본 비공개)
4. 공유 문서 미리보기 및 최종 승인
5. 공유 문서 미리보기 및 최종 승인
6. 링크는 발급 직후 한 번만 복사·전달 가능
7. 카카오톡·문자 등으로 URL 전달
8. 수신자는 별도 인증·앱 설치 없이 웹 링크로 고정본 열람

<aside>

#### 참고!! 레포트 유형은 총 3가지

1. **돌봄 설명서 (3.1)**

대상자의 정보를 지속적으로 축적하는 문서. 일기를 작성하고 AI가 추출한 정보를 보호자가 승인하면 기존 설명서에 자동 반영·갱신되는 구조.

1. **일일 기록 (2.4)**

특정 날짜의 일기에서 추출된 돌봄 정보를 정리한 문서. 해당 날짜에 어떤 일이 있었고 어떻게 대응했는지 확인하는 용도. 

1. **주간 리포트 (2.5)**

일주일간 축적된 돌봄 기록을 분석해 반복적으로 나타난 행동과 대처 경향을 정리한 문서.

</aside>

세 문서 모두 '공유하기' → 4.1 공유 설정 → 4.2 미리보기 → 4.3 링크 발급의 동일한 흐름 사용.

설명서 자체는 자동 갱신되지만, 이미 발급한 공유 링크의 문서는 공유 당시 내용이 유지되는 고정본

## 2-4. AI 분석 흐름

1. 음성·텍스트 일기 입력
2. STT 변환 및 원문 확인
3. AI 분석 요청
4. 긴급 위험 표현 우선 판별
5. 일반 기록인 경우 공감 한 줄·돌봄 정보 추출
6. 돌봄 공백 가능성 감지 시 보호자 확인
7. 소진 안내 조건 충족 시 지원 안내 카드 표시(일반 기록 기능 유지)
8. 보호자 검토·승인 후 설명서 반영(공백 자동 감지는 P1)

| 분석 결과 | 시스템 처리 |
| --- | --- |
| 일반 기록 | 공감 한 줄 → 정보 추출 → 검토·승인 |
| 돌봄 공백 가능성(P1) | 후속 기능: 상황 확인 → 공공자원 탐색 |
| 소진 신호 누적 | 긴급돌봄·가족휴식지원·부모상담 안내 |
| 긴급 위험 표현 | 일반 AI 대화 중단 → 일기 저장 → 고정 안전 안내 → 전문 지원 창구 제공 (공감 한줄, 정보 추출 금지) |

**우선순위:** 긴급 위험 대응 → 일반 돌봄 분석 및 지원 안내

- 권한 변경 및 철회는 서버 측에서 검증

# 05. 공통 시스템 및 데이터 정책

## 5-1. AI 처리 정책

| 기능 | 처리 기준 |
| --- | --- |
| STT | 음성 → 텍스트 변환, 확인 후 원본 음성 삭제 |
| 공감 메시지 | 1~2문장, 상담·진단·치료 조언 제외 |
| 정보 추출 | 원문 기반 JSON 구조화 |
| 승인 | 보호자 승인 정보만 돌봄 DB 반영 |
| 문서 생성 | 승인된 돌봄 정보 기반 |
| 맞춤형 공유 | 문서 유형·보호자가 선택한 공개 섹션으로 고정본 구성. 수신자 유형별 AI 재구성 없음 |
| 공백 감지 | P1: 명시적 상황 추출, 보호자 확인 후 처리. MVP는 직접 조건 검색 |
| 소진 감지 | 일정 기간·횟수 기준 누적 판단 |
| 위기 감지 | 일반 AI 응답 중단, 고정 안전 안내 제공 |

## 5-2. 데이터 및 API

| 데이터·API | 활용 목적 |
| --- | --- |
| STT API | 음성 일기 텍스트 변환 |
| LLM API | MVP: 공감·돌봄 정보 추출 및 안전 분기. 공백 자동 감지·공유 문서 AI 요약·추천 이유 생성은 P1 |
| 돌봄 기록 DB | 승인된 돌봄 정보 관리 |
| 사용자·권한 DB | 계정, 공동 관리자, 공유 권한 관리 |

| 경기데이터드림 장애인 관련 시설 | 대체 돌봄 자원 후보 탐색 |

## 5-3. 공유·접근 권한 정책

- 공유 대상자 유형별 자동 구성은 없습니다. 공유 링크는 7일 고정 유효, 발급 직후에만 복사 가능, 별도 본인 확인 없이 접근 가능하며 링크 접근 중지를 지원합니다.
- 링크를 가진 사람만이 열람 가능:별도 확인 절차 없이 "추측 불가능한 랜덤 토큰 링크 + 만료일 + 철회”
- 문서별 공유 권한을 서버에서 검증
- 공유 고정본에 승인된 정보만 포함
- 접근 만료 및 철회 지원공동 관리자 삭제 시 신규 공유·열람 제한 및 해당 관리자가 발급한 활성 공유 링크 즉시 철회
- 공유 문서별 보호자가 선택한 공개 범위만 유지(수신자 유형별 기본 정책 없음)
- 일반 수신자의 문서 수정·재공유 기능 미제공

## 5-4. 개인정보 정책

- 필수 동의 항목 4종(개인정보·민감정보·AI 처리·대상자 정보 처리 권한 확인)을 버전과 함께 기록합니다. 수신자용 공유본에는 이름·나이만 기본 포함하고 지역·출생 연도는 제공하지 않습니다.
- 일기 원문·소진·위기 정보 외부 공개 금지
- 성인 돌봄 대상자의 개인정보 처리 권한 확인
- 필수 정보만 수집
- 원본 음성 STT 완료 후 삭제
- 비공개 소진 신호 기록 별도 저장
- 외부 LLM 사용 시 민감정보 전송 및 저장 조건 검토
- 공유 토큰·초대 요청·접근 권한의 서버 측 검증 필수
- 데이터 보존·삭제 기간

## 5-5. UI·접근성 정책

- 고령 보호자 기준 큰, 직관적 글씨·버튼

# 06. 개발 우선순위 및 검수

## 6-1. MVP 우선순위

해커톤 MVP는 React 모바일 웹입니다. 주간 리포트, AI 돌봄 공백 감지·저장, AI 기반 추천 이유·공유 요약은 P1이며, 소진·위기 고정 안내 및 조건 검색은 P0로 유지합니다.

| 우선순위 | 기능 |
| --- | --- |
| **P0 필수** | 계정·온보딩, 일기 작성, AI 추출·승인, 일일 기록, 돌봄 설명서, 공통 링크 공유, 공동 관리자 초대·수락, 공백 지원, 소진·위기 안전 대응 |
| **P1 후순위** | 주간 패턴 리포트 생성·공유, AI 돌봄 공백 자동 감지·확인·저장, AI 추천 이유·공유 요약, 상세 기록 관리 고도화 |
| **MVP 제외** | 실시간 기관 매칭, 자동 신청·예약, AI 심리 상담, 자동 신고, 기관 운영 대시보드 |
