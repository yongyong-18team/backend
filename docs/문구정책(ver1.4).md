# 문구 정책(ver.1.4)

# 용용톤 전체 화면 UI 문구 및 정책 확정안 v1.4

> **문서 설명**
> 
> 
> Figma 의 디자인 섹션과 PRD ver.1.1, TRD·ERD·AI·API 명세 v1.4를 기준으로 작성했습니다. 기존 디자인 문구를 우선 유지하되, 입력 오류·팝업·토스트·로딩·빈 화면 등 추가 상황의 문구와 표시 정책을 함께 정리했습니다.
> 
> **서비스명은 아직 미정**이며, 소셜 로그인과 주간 리포트는 디자인·프로토타입에 유지합니다.
> 
> 본 문서는 기획팀의 **화면 문구 및 정책 전달안**입니다. 아래의 [추가 제안]·[확인 필요] 항목은 기존 개발 문서에서 확정된 사항이 아닙니다.
> 

## . 정책 출처 표시 기준

| 구분 | 의미 |
| --- | --- |
| **[개발 확정]** | TRD·ERD·AI·API 명세 v1.4에 명시된 구현 기준 |
| **[기획 확정]** | 기획서·PRD 또는 기획 피드백에서 결정한 사항 |
| **[디자인·프로토타입]** | Figma 화면에 유지하지만 MVP 개발 범위와 구분되는 기능 |
| **[추가 제안]** | 개발 문서에 확정되지 않은 UI 문구·팝업·표시 방식의 기획 제안 |
| **[확인 필요]** | 개발팀과 추가 합의하거나 검증해야 하는 사항 |

**표기 원칙:** 기존 Figma에 이미 있는 화면 문구는 그대로 유지할 수 있으며, 아래 표에서 [추가 제안]으로 표시한 문구는 개발 명세에 직접 적힌 문장이 아니라 기획팀 전달용 제안 문구입니다.

## 최종 전달 원칙

1. **[개발 확정]** 항목은 기존 명세의 구현 기준을 따릅니다.
2. **[기획 확정]** 항목은 기획팀이 개발팀에 전달할 문구·화면 정책으로 사용합니다.
3. **[디자인·프로토타입]** 항목은 화면에서는 유지하되 실제 서버 구현을 보장하지 않습니다.
4. **[추가 제안]** 항목은 기획팀의 신규 문구안으로, 개발팀이 기존 오류 응답과 UI 동작을 확인한 후 적용합니다.
5. **[확인 필요]** 항목은 최종 합의 전까지 확정된 개발 정책으로 취급하지 않습니다.
