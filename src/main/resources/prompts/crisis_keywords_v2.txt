# 초안: 백엔드 B 작성, 기획 확인 전(AI 명세 9장 미결 2번). 기획이 목록을 주면 v3로 바꾼다.
# v1(명세 예시 5개)에 명세 3-5 범위 중 빠져 있던 표현을 더했다. 평가셋 30건으로 놓침·오탐을 확인한다(CrisisKeywordCheckerTest).
# 범위는 보호자 본인의 1인칭 표현만. "죽겠다" 단독, "자해"·"때렸다" 단독은 넣지 않는다(관용 표현·대상자 행동 기록과 구분 안 됨).
# 지금 다친 응급 상황(예: 의식이 없다)은 보호자의 의도가 아니라 사전 범위 밖이다. LLM safetyLevel로 잡는다.
